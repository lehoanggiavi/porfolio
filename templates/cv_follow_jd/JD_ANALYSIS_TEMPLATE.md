## Requirement-to-evidence matrix

| JD requirement | Priority | Evidence in canonical CV/project | Status | CV action |
|---|---|---|---|---|
| Example: Python | Must-have | Canonical Technical Skills; verified projects | Matched | Keep near the start of Skills |
|  |  |  | Matched / Partial / Missing |  |

Status meanings:

- `Matched`: direct, verifiable evidence exists.
- `Partial`: adjacent evidence exists, but the full requirement is not proven.
- `Missing`: no reliable evidence exists; do not add it to the CV.
